# SUBCULT

**Software for independent culture.**

We build tools for people making, sharing, and organizing independent culture—from finding a clip or searching a recording to making music visuals, publishing a link page, and running a show.

Explore the public apps, deploy the archive software, or follow the projects still in development.

[Website](https://subcult.tv) · [Products](https://subcult.tv/products) · [Development on Gitea](https://git.subcult.tv/subculture-collective) · [Contact](mailto:info@subcult.tv)

## Explore the work

| Project | What it does | Where to start |
| --- | --- | --- |
| **clpr** | Find Twitch clips by creator, topic, and tag. Keep playlists for the ones you want to share. | [Public app](https://clpr.tv) · [Source](https://git.subcult.tv/subculture-collective/clpr) |
| **HasanAra** | Find a passage in HasanAbi broadcasts and return to the original recording at its timestamp. **Check machine transcripts against recordings before quoting.** | [Public archive](https://hasanara.tv) · [Source](https://git.subcult.tv/subculture-collective/hasanara) |
| **Rekolekt** | Turn recordings into a searchable archive with timestamped transcripts and links back to the source. Self-hosted software; the engine behind HasanAra. **Check machine transcripts against recordings before quoting.** | [Source and deployment](https://git.subcult.tv/subculture-collective/rekolekt) |
| **Undertow** | Layer visuals, artwork, and timed lyrics around a track, then export video in your browser. **Export support varies by browser and device.** | [Public editor](https://undertow.subcult.tv) · [Source](https://git.subcult.tv/subculture-collective/undertow) |
| **Kork** | Give your work, channels, and events a home on one link page. | [Public app](https://kork.subcult.tv) · [Source](https://git.subcult.tv/subculture-collective/kork) |
| **Patchwork** | Explore a neighborhood board for requests, offers, and resources. **Pre-alpha demonstration; no real help requests.** | [Demonstration](https://patchwork.subcult.tv) · [Source](https://git.subcult.tv/subculture-collective/patchwork) |
| **Subcult OS** | A run sheet for small shows: planning, crew, free reservations, door check-in, and close-out. **In development.** | [Source](https://git.subcult.tv/subculture-collective/subcult-os) |

## Contribute or collaborate

Found a bug, have an idea, or want to help build something? Start with the project's README and contribution guide, then open an issue on Gitea.

Development, pull requests, and CI live on [Gitea](https://git.subcult.tv/subculture-collective). GitHub hosts publishing copies.

For creative collaborations or questions about the work, email [info@subcult.tv](mailto:info@subcult.tv).
